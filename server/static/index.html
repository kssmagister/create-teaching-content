    Ablauf

    1. Material sammeln → sources/ hochladen (Texte, PDFs, Bilder)
    2. editorial.json erzeugen (Button) oder von Hand schreiben
    3. Ergebnis inhaltlich prüfen – kein automatischer Fakten-Check!
    4. Titelseite gestalten (optional)
    5. PDF bauen
    Terminal-Befehle (Fallback)
    ingest.py und export.py gibt es auch als Buttons direkt in den Karten rechts – diese Befehle sind nur ein Fallback, z. B. wenn der Docker-Socket auf einem System mal nicht verfügbar ist.
    ingest.py – wandelt Scans/Fotos (OCR) und weitere Formate (PPTX, XLSX, HTML) in sources/ zu Markdown. Auf dem Server, im Projektordner: docker compose --profile ingest run --rm ingest python ingest.py units/<einheit>
    export.py – erzeugt statt PDF ein Word/EPUB/ODT-Dokument. Auf dem Server, im Projektordner: docker exec ctc python export.py units/<einheit> --format docx
    Wähle links eine Einheit oder lege eine neue an. Der Ablauf ist links in der Kurzanleitung beschrieben.
